# nanoDiffusionLab 中文逐步教程

这套教程面向第一次接触语言模型训练，或者已经会使用 PyTorch、但还没有完整跑过语言模型
实验的读者。它不是论文摘要，也不是只给出一串命令的安装说明，而是从数据、张量、模型、
训练、采样、分布式运行一直走到正式评测的完整复现指南。

教程的第一条主线是从零训练一个掩码扩散语言模型，完整经过随机破坏、双向预测、掩码位置
loss、检查点和多轮并行采样。第二条主线是仓库内置的完整 GPT 风格自回归语言模型，包括因果
训练、困惑度验证与键值缓存生成。两条主线最后汇合为同一主干上的公平实验，而不是只把 GPT
当作一张结果表中的外部对照。

教程直接使用仓库中的真实实现。你在教程中运行的 `train.py`、`sample.py` 和评测脚本，就是
正式实验所使用的代码，不存在一套为了讲解而简化、最后又无法迁移到真实实验的平行实现。

## 你最终会完成什么

完整走完后，你应该能够：

- 解释自回归语言模型与掩码扩散语言模型的训练信号有何不同；
- 独立启动一条完整的扩散语言模型训练与采样流程；
- 独立使用仓库中的 GPT 风格模型训练、验证和生成文本；
- 看懂输入张量从词元编号到注意力输出再到词表 logits 的形状变化；
- 在字符数据上分别训练和采样两种模型；
- 准备固定版本的 TinyStories 与 GPT-2 BPE 分片；
- 在单卡或多卡上启动约一亿参数的训练，并正确恢复检查点；
- 区分两种目标各自的验证指标，避免直接比较不等价的 loss；
- 复现生成质量、延迟、吞吐、显存与盲评报告；
- 根据日志定位显存不足、NCCL、数据路径和恢复训练问题。

## 教程中的路径和命令约定

除非特别说明，所有命令都从仓库根目录执行。先进入仓库：

```bash
cd nanoDiffusionLab
```

教程中的 `$` 代表普通终端提示符，不需要输入。形如 `out/...` 的目录是运行产物，默认不会
提交到 Git。命令中出现的显卡数量、批量大小和运行时间是参考值，应当根据自己的机器调整。

每章末尾都有“完成检查”。它不是练习题，只用来确认你是否得到了继续下一章所需的文件、输出
或概念。如果某一项不符合，优先查看该章的排错部分，再查看
[常见问题排查](12_常见问题排查.md)。

## 三个贯穿全程的原则

第一，比较训练目标时要固定能固定的条件。这个项目让 AR 与 MDLM 使用相同数据、分词器、
上下文长度、Transformer 主干与输入词元预算。

第二，不把名字相同的数字误认为相同指标。AR 的交叉熵对应下一个词元预测，可以转换为
perplexity；当前 MDLM 的 loss 是随机掩码位置上的去噪交叉熵，不能直接与 AR perplexity 排名。

第三，报告真实系统条件。显卡型号、互联拓扑、精度、进程数、批量大小和软件版本都会影响
吞吐与显存。教程会告诉你这些信息保存在哪里，而不是只展示最好看的一个数字。
