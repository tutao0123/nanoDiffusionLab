# 07｜字符级训练与采样

这是第一次真正运行训练。先用 10 step 验证完整链路，再决定是否训练到能够生成可读文本。十步
模型几乎一定输出乱码；只要 loss、checkpoint 和采样器正常，它就是成功的 smoke test。

## 准备数据

```bash
mkdir -p data/tinyshakespeare
curl -L https://raw.githubusercontent.com/karpathy/char-rnn/master/data/tinyshakespeare/input.txt \
  -o data/tinyshakespeare/input.txt
wc -c data/tinyshakespeare/input.txt
```

文件应约为 1.1 MB。检查开头：

```bash
head -5 data/tinyshakespeare/input.txt
```

## 先看配置

```bash
sed -n '1,200p' configs/shakespeare_char.py
```

默认配置是 6 层、6 头、隐藏维度 384、上下文 256 的 MDLM。`vocab_size=65` 是 Tiny
Shakespeare 常见字符数；加载器仍会从真实文件计算词表，并在必要时更新配置。

## 十步 MDLM smoke test

使用独立输出目录，不覆盖以后可能存在的正式字符模型：

```bash
python train.py \
  --config configs/shakespeare_char.py \
  --objective masked_diffusion \
  --out-dir out/tutorial-shakespeare-mdlm-smoke \
  --max-iters 10 \
  --eval-interval 5 \
  --eval-iters 2 \
  --batch-size 4
```

有 CUDA 时程序自动使用单张 GPU；没有 CUDA 时使用 CPU。输出开头类似：

```text
masked_diffusion | ...M params | device=cuda | world_size=1 | ...
step 0: tokens=0 val_loss=...
iter 1: loss=... lr=... tokens=... tok/s=...
```

具体 loss 和吞吐依赖设备与随机状态，不要照抄数值作为成功标准。你要确认 loss 是有限数字、
step 能向前推进、进程正常退出。

## 查看运行产物

```bash
find out/tutorial-shakespeare-mdlm-smoke -maxdepth 2 -type f -printf '%p\n' | sort
```

主要文件：

| 文件 | 内容 |
|---|---|
| `run.json` | 解析后的配置、环境、数据描述、参数量和计划 step |
| `metrics.jsonl` | 每次 train/eval 事件，一行一个 JSON |
| `last.pt` | 最后状态，可继续训练 |
| `best.pt` | 验证 loss 最优状态 |
| `summary.json` | 最终指标、词元数、吞吐、时间与峰值显存 |
| `meta.json` | 字符词表的 `stoi` 与 `itos` |
| `source/` | 本次运行开始时的小型源码和配置快照 |

检查摘要：

```bash
python -m json.tool out/tutorial-shakespeare-mdlm-smoke/summary.json
```

查看 JSONL 最后几行：

```bash
tail -5 out/tutorial-shakespeare-mdlm-smoke/metrics.jsonl
```

## 观察 MDLM 去掩码动画

```bash
python sample.py \
  --checkpoint out/tutorial-shakespeare-mdlm-smoke/best.pt \
  --length 80 \
  --steps 8 \
  --temperature 1.0 \
  --top-k 20 \
  --seed 7 \
  --show-steps
```

终端会打印 `step 01` 到 `step 08`。为便于显示，尚未恢复的 mask 在字符解码时临时显示为词表
起始字符；最后一行应当没有 mask。十步训练的字符排列不合理是正常的。

## 十步 AR smoke test

```bash
python train.py \
  --config configs/shakespeare_char.py \
  --objective autoregressive \
  --out-dir out/tutorial-shakespeare-ar-smoke \
  --max-iters 10 \
  --eval-interval 5 \
  --eval-iters 2 \
  --batch-size 4
```

切换 objective 时，命令行覆盖逻辑会：

- 把 attention 改为 causal；
- 移除 mask token；
- 关闭 time conditioning；
- 使用 next-token loss 和 AR 验证指标。

采样：

```bash
python sample.py \
  --checkpoint out/tutorial-shakespeare-ar-smoke/best.pt \
  --prompt "ROMEO:" \
  --length 80 \
  --temperature 1.0 \
  --top-k 20 \
  --seed 7
```

AR 输出会保留 prompt 并继续追加字符。

## 训练到能够观察文本结构

确认 smoke test 后，可以使用默认 5,000 step。建议使用新目录：

```bash
python train.py \
  --config configs/shakespeare_char.py \
  --objective masked_diffusion \
  --out-dir out/tutorial-shakespeare-mdlm
```

AR：

```bash
python train.py \
  --config configs/shakespeare_char.py \
  --objective autoregressive \
  --out-dir out/tutorial-shakespeare-ar
```

运行时间取决于 GPU。不要在 CPU 上盲目等待完整 5,000 step；先根据前几十步的 `step_seconds`
估算总时间。

## 如何估算剩余时间

假设稳定后每 step 为 0.20 秒，还剩 4,000 step：

```text
4,000 × 0.20 秒 = 800 秒 ≈ 13.3 分钟
```

评估和保存 checkpoint 会额外增加时间，因此实际略长。训练日志中的 `training_seconds` 只累计
训练 step，最终 `elapsed_seconds` 还包含评估、保存和其他开销。

## 从已有 checkpoint 继续

```bash
python train.py \
  --config configs/shakespeare_char.py \
  --objective masked_diffusion \
  --out-dir out/tutorial-shakespeare-mdlm \
  --resume
```

不带路径的 `--resume` 默认读取当前输出目录的 `last.pt`。恢复要求模型结构一致；修改层数、隐藏
维度或 objective 后不能精确加载旧状态。

## 常见问题

### prompt 中出现词表没有的字符

字符模型只能编码训练文本中出现过的字符。`sample.py` 会在 `stoi[char]` 处报错。换成词表内
字符，或使用 `meta.json` 检查词表。

### 十步训练一开始就很慢

step 0 会先做 validation 并保存 checkpoint。教程已经把 `eval_iters` 降到 2；正式配置默认评估
更多 batch，因此不能只根据第一次输出间隔判断训练吞吐。

### `best.pt` 和 `last.pt` 有何区别

`best.pt` 是验证 loss 最低时保存的模型，适合采样；`last.pt` 是最新完整状态，适合恢复训练。

## 完成检查

- AR 与 MDLM 十步训练都正常退出；
- 两个输出目录都包含 `run.json`、`metrics.jsonl`、`last.pt`、`best.pt` 和 `summary.json`；
- MDLM `--show-steps` 能展示多轮并行恢复；
- AR 采样能保留 `ROMEO:` prompt；
- 你没有把十步乱码当作模型质量结论。
