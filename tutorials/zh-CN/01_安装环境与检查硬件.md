# 01｜安装环境与检查硬件

这一章把仓库安装成可运行状态，并确认 PyTorch 实际看到的 CPU、CUDA 和显卡。不要只根据
`nvidia-smi` 判断环境正常：驱动能看到显卡，不代表当前 Python 中的 PyTorch 能使用 CUDA。

## 获取代码

```bash
git clone git@github.com:tutao0123/nanoDiffusionLab.git
cd nanoDiffusionLab
```

如果没有配置 GitHub SSH，也可以使用 HTTPS：

```bash
git clone https://github.com/tutao0123/nanoDiffusionLab.git
cd nanoDiffusionLab
```

确认当前提交和工作区：

```bash
git log -1 --oneline
git status --short
```

第二条命令在全新克隆中应当没有输出。

## 创建独立 Python 环境

项目要求 Python 3.10 或更高版本。使用标准虚拟环境：

```bash
python3 -m venv .venv
source .venv/bin/activate
python --version
```

如果服务器已经使用 Conda，也可以创建独立环境：

```bash
conda create -n nanodiffusion python=3.12 -y
conda activate nanodiffusion
```

不要在同一次安装中混用系统 Python、Conda Python 和虚拟环境 Python。遇到“明明安装过却
import 不到”的问题时，首先执行：

```bash
which python
python -m pip --version
```

两条输出应当指向同一个环境前缀。

## 安装依赖

只运行字符实验与测试：

```bash
python -m pip install -U pip
python -m pip install -e ".[dev]"
```

准备 TinyStories 还需要数据依赖：

```bash
python -m pip install -e ".[data,dev]"
```

完整生成评测还需要 API 与绘图依赖：

```bash
python -m pip install -e ".[data,eval,viz,dev]"
```

`-e` 表示 editable install。修改仓库中的 Python 文件后无需重新安装，当前环境会直接使用新
源码。

## 检查 PyTorch 与 CUDA

```bash
python - <<'PY'
import torch

print("torch:", torch.__version__)
print("cuda build:", torch.version.cuda)
print("cuda available:", torch.cuda.is_available())
print("gpu count:", torch.cuda.device_count())
for index in range(torch.cuda.device_count()):
    props = torch.cuda.get_device_properties(index)
    print(index, props.name, f"{props.total_memory / 1024**3:.1f} GiB")
PY
```

有 NVIDIA 显卡时，`cuda available` 应为 `True`，显卡数量应与准备使用的设备一致。CPU 环境中
为 `False` 并不是错误，字符级流程仍然可以运行。

## 检查驱动、占用和拓扑

```bash
nvidia-smi
nvidia-smi topo -m
```

关注三件事：

1. 每张卡是否有其他进程占用显存；
2. GPU 之间是否显示 NVLink、PIX、PXB、PHB 或 SYS；
3. GPU 是否跨 NUMA 节点。

参考服务器的 4 张 A40 之间均为 PHB，没有 NVLink，并位于同一 NUMA 节点。因此约一亿参数
规模优先使用 DDP，让每张卡保存完整模型、处理不同数据，再同步梯度；这里没有必要优先引入
Tensor Parallel、FSDP 或 ZeRO-3。

## 检查 BF16 支持

```bash
python - <<'PY'
import torch

if torch.cuda.is_available():
    print("bf16 supported:", torch.cuda.is_bf16_supported())
else:
    print("CPU-only environment")
PY
```

A40 支持 BF16。若设备不支持，可以在自己的配置文件中把 `dtype` 改为 `float16` 或
`float32`。FP16 使用梯度缩放；BF16 通常具有更宽的数值范围，是 Ampere 及更新数据中心显卡
上的首选。

## 先运行测试

```bash
python -m pytest
python -m ruff check .
```

测试覆盖注意力方向、掩码破坏、数据分片、采样、检查点工具和评测统计。它不能替代真实训练，
但可以在下载数据和占用 GPU 前发现安装或源码问题。

## 常见问题

### `torch.cuda.is_available()` 为 False

先比较 `nvidia-smi` 与 `python -c "import torch; print(torch.version.cuda)"`。前者失败通常是驱动
或容器设备映射问题；前者成功而后者为 `None`，通常安装了 CPU 版 PyTorch。

### 安装 `tiktoken` 或 `datasets` 失败

确认 Python 至少为 3.10，并先升级 pip。字符级教程不依赖这两个包，可以先只安装 `[dev]`。

### 多卡数量不符合预期

检查 `CUDA_VISIBLE_DEVICES`：

```bash
printf '%s\n' "${CUDA_VISIBLE_DEVICES:-not set}"
```

如果只想使用指定显卡，可以在命令前设置，例如 `CUDA_VISIBLE_DEVICES=0,1`。

## 完成检查

- `python -m pytest` 全部通过；
- 你知道当前 `python` 来自哪个环境；
- 有 GPU 时，PyTorch 能列出正确的设备数量和显存；
- 你已经确认准备使用的显卡没有意外占用。
